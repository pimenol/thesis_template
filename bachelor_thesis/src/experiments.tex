\chapter{Experiments and Results\label{chap:experiments}}

\section{Experimental Setup}

We fine-tuned each of the four pre-trained language models (\ac{BROWCzech}, \ac{RetroMAE}, \ac{DeBERTaV3} base, and \ac{DeBERTaV3} large) on our journalistic dataset. All models used the same data splits (56,788 articles for training, with separate validation and test sets as described in Chapter~\ref{chap:data_collection}). Training was performed in two stages: first we trained only the classification head for 6 epochs, then we unfroze the full model and trained all layers for 5 more epochs. This two-stage schedule (11 total epochs) was chosen to stabilize training. The models were implemented in \textbf{PyTorch}(\cite{paszke2019pytorch}) and fine-tuned using the \textbf{Hugging Face Transformers} library (\cite{wolf2020transformers}). We used mixed-precision (FP16) on an NVIDIA H100 PCIe GPU; the total training time for all experiments was about 27 hours. To support experimentation, we logged metrics with \textbf{MLflow} and used \textbf{Pandas} tools to handle the data; class labels were encoded with \textbf{torchnlp.encoders.LabelEncoder}.

\begin{itemize}
  \item \textbf{Dataset}: Training set of 56,788 articles; validation and test splits as in Chapter~\ref{chap:data_collection}.
  \item \textbf{Environment:} PyTorch and Hugging Face Transformers, mixed-precision training (FP16) on an NVIDIA H100 GPU (~27 GPU-hours).
  \item \textbf{Training procedure:} Two-stage fine-tuning – 6 epochs training of the new classification head (base layers frozen), followed by 5 epochs of full-model training.
  \item \textbf{Tools:} MLflow (experiment tracking), pandas/csv (data handling), torchnlp LabelEncoder (label encoding).
\end{itemize}

\section{Neural Model Results}

The test performance of the four neural models is compared in Table~\ref{tab:validation_scores}. The weighted F1 score of each model are shown. As expected, \ac{BROWCzech} (a simpler encoder) had the lowest performance, while the \ac{DeBERTaV3} large models achieved higher accuracy. \ac{DeBERTaV3} base outperformed \ac{RetroMAE} and \ac{BROWCzech}, and \ac{DeBERTaV3} large improved slightly further. The best neural model was \ac{DeBERTaV3} large, with a weighted F1 around 0.766 and accuracy around 0.77. 

This high-level results are consistent with our expectations. \ac{DeBERTaV3}’s stronger architecture led to better classification of article quality. In particular, the large model’s extra capacity helped capture nuanced journalistic features. Still, all models showed difficulty with the rare \ac{Class 3}. To illustrate the errors, Figure~\ref{fig:conf_matrix_llm_test} shows the confusion matrix for the \ac{DeBERTaV3} large model on the test data. We see that the most common class (\ac{Class 1}) had the most true positives, but it was sometimes confused with \ac{Class 2} (Class 2). \ac{Class 3} (Class 3) remains very hard: only a small number of high-quality articles were correctly identified, and many were misclassified as Class 1 or 2. This reflects the severe class imbalance (high-quality articles are <1\% of the data).

\section{CatBoost Model}

We also trained a \ac{CatBoost} classifier using features created in Section~\ref{sec:features_creating}. The \ac{CatBoost} model required only about 1 minute of training on the same GPU. This model achieved a weighted F1 around 0.716 (accuracy 72,8\%). The \ac{CatBoost} model was fast to train and already competitive with the neural models. However, it did not outperform the best neural model (\ac{DeBERTaV3} large). The \ac{CatBoost} model’s confusion matrix (Figure~\ref{fig:conf_matrix_catboost_test}) shows that it struggled with the same classes as the neural models, particularly \ac{Class 3}.

\section{Hybrid Model Results}

The final hybrid model combined the strengths of both approaches: we fed the four logit scores from \ac{DeBERTaV3} large into the \ac{CatBoost} classifier alongside other features. This hybrid (ensemble) model gave the best results of all experiments. On the test set, the hybrid model achieved a weighted F1 score of about 0.779 and an accuracy of roughly 71,1\%, outperforming each individual model. These values surpass the single-model baselines and approach the human agreement upper bound ($\approx$80\%) noted in Chapter~\ref{sec:editor_analysis}. The results demonstrate that \ac{CatBoost} could effectively use the extra information in the \ac{DeBERTaV3} outputs to correct some mistakes. Figure~\ref{fig:conf_matrix_hybrid_test} shows the confusion matrix for the hybrid model on the test data. The matrix indicates improved true-positive counts in most classes. Misclassifications between Class 1 and 2 remain the largest source of error, but overall the model is more calibrated. The hybrid model’s gains are especially clear in classifying borderline articles: by seeing the full DeBERTa prediction vector rather than just a single guess, \ac{CatBoost} learned to distinguish subtle cases better. This is evident in the confusion matrix, where fewer \ac{Class 2} are mistaken for \ac{Class 1} compared to the purely neural model.

\section{Summary of Results}

In summary, the performance ranking of the models shown in the Table~\ref{tab:validation_scores} were as follows: Hybrid (DeBERTaV3 large + \ac{CatBoost}) $>$ DeBERTaV3 large $>$ DeBERTaV3 base $>$ RetroMAE $>$ BROWCzech $>$ \ac{CatBoost}. The hybrid model achieved the best weighted F1 ($\approx$0.779) and accuracy ($\approx$0.781), thanks to combining neural embeddings with gradient boosting. The \ac{CatBoost} classifier alone was fast to train ($\approx$1 minute) and already competitive, but the ensemble yielded a clear improvement. Across all models, we consistently measured weighted F1 and accuracy on the test set. The improvement from the best single model (DeBERTaV3 large) to the hybrid model is small but consistent, indicating that the additional decision-tree model helps correct a subset of errors. These results, together with the confusion matrices and charts above, show that our automated system achieves near human performance on Czech news quality classification (approaching the human agreement benchmark).
