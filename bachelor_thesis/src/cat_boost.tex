\section{CatBoost}\label{sec:catboost}
We employed \ac{CatBoost} introduced by \cite{prokhorenkova2018catboost}, a gradient boosting classifier, to predict article quality using the engineered feature set. \ac{CatBoost} was chosen for its ability to handle categorical data natively and its robustness on imbalanced datasets.
In our case, this meant we could include metadata and content-based attributes together without extensive preprocessing. For example, \ac{CatBoost} can directly ingest a categorical feature like channel ID (the article's source channel) by using an ordered encoding scheme that computes target statistics from prior data points, thereby avoiding target leakage.

Another architectural advantage of \ac{CatBoost} is its use of symmetric (oblivious) decision trees, where all splits at a given tree level use the same condition.
This yields consistent, fast models and, coupled with the ordered boosting algorithm, helps reduce overfitting. These properties made \ac{CatBoost} well-suited to our feature-based approach.

\subsection{Motivation and Suitability} 
The motivation for using \ac{CatBoost} was twofold. 

First, it seamlessly handles the mix of linguistic complexity metrics, structural composition indicators, readability scores, and metadata features from Section \ref{sec:features_creating}. Unlike some algorithms, it does not require one-hot encoding or manual scaling of categorical inputs, preserving useful information encoded in features like genre or source. 

Second, \ac{CatBoost}'s robustness to class imbalance was critical: our dataset's quality classes were highly skewed. \ac{CatBoost} provides built-in options for balancing classes (e.g. an auto\_class\_weights = "SqrtBalanced" setting) to ensure minority classes are not ignored. This capability, combined with the algorithm's general resilience to overfitting, made it a strong candidate for our task.

\subsection{Architecture and Feature Processing} 

We configured \ac{CatBoost} to utilize all four feature groups described earlier. Internally, the model builds symmetric decision trees that split on the most informative features at each depth. The ordered boosting procedure meant that categorical features were transformed on the fly using only preceding training examples, which prevented the model from learning spurious correlations. One categorical feature, channel ID, was initially included among the inputs and, as expected, \ac{CatBoost} identified it as extremely predictive of quality. This indicated that the source/publisher was a dominant signal for quality in our data. However, relying on this metadata goes against the goal of assessing content intrinsic quality. \textbf{We therefore removed channel ID in the final model}. After this adjustment, \ac{CatBoost} focused on the content-based features (linguistic, structural, readability, etc.), and no single feature dominated the importance. The model could thus base its predictions on a combination of stylistic and structural characteristics of the text rather than a possibly biasing identifier.

\subsection{Hyperparameter Tuning}

To optimize multi-class classification performance, we performed a comprehensive search over key \ac{CatBoost} hyperparameters. The tuning process focused on improving the weighted F1 score on the validation set while maintaining generalization.

\subsubsection*{Search Space and Strategy}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Loss Function:} Compared \ac{CatBoost}'s standard MultiClass objective with a one-vs-all setup.
    \item \textbf{Boosting Iterations:} Varied the number of trees to control training duration and overfitting risk.
    \item \textbf{Tree Depth:} Tuned in the range of 5–10 to balance model expressiveness and regularization.
    \item \textbf{L2 Regularization:} Adjusted via the \texttt{l2\_leaf\_reg} parameter to penalize overly sharp splits.
    \item \textbf{Randomness Control:} Tuned the \texttt{random\_strength} parameter to inject beneficial noise into the tree-splitting process and smooth decision boundaries.
\end{itemize}

\subsubsection*{Best Configuration and Observations}
\begin{itemize}[leftmargin=1.5em]
    \item The optimal setup used:
    \begin{itemize}
        \item \texttt{MultiClass} loss function.
        \item 1500 boosting iterations.
        \item Tree depth of 7 to 9.
        \item Small but non-zero L2 regularization.
        \item Moderate \texttt{random\_strength} value to improve generalization.
    \end{itemize}
    \item \textbf{Early Stopping:} Enabled with a patience of 200 rounds.
    \begin{itemize}
        \item Prevented overfitting by stopping training once validation performance plateaued.
        \item Empirically validated our choice of 1500 trees, as performance typically stabilized before this point.
    \end{itemize}
\end{itemize}

\subsubsection*{Outcome}
All hyperparameters were jointly tuned using validation-based feedback. The selected configuration maximized the weighted F1 score and produced balanced class-wise performance across the multi-class prediction task.

\subsection{Feature-Group Importance} 
To understand the contribution of each feature group to the final model, we computed the mean feature importance across all features in each group. This was done by aggregating the importance scores assigned by \ac{CatBoost} to each feature and normalizing them to sum to 1. The results are shown in \reftab{tab:feature_importance}, which illustrates the relative importance of each feature group in the final model.

The table shows that none of the groups dominated the model's decisions, indicating that \ac{CatBoost} was \textbf{able to learn from a diverse set of features}. The structural composition and readability metrics were the most important, suggesting that the model relied heavily on these aspects to assess article quality. Linguistic complexity and metadata also contributed significantly, but to a lesser extent. This balanced feature importance distribution aligns with our expectations: high-quality articles should exhibit a combination of good structure, readability, and linguistic sophistication.

\subsection{Performance and Practical Considerations}
With \textbf{weighted F1=0.725} the final \ac{CatBoost} model lags the neural network yet surpasses simpler baselines and remains attractive for two reasons:

1. Speed – CPU inference takes $< 3$ ms per article, enabling real-time scoring.

2. Interpretability – per-instance SHAP values help editors understand which textual properties influenced a given prediction.

Consequently, \ac{CatBoost} serves as a complementary component in the ensemble pipeline, offering a lightweight, transparent alternative to transformer-based models. 

\section{Hybrid Model: CatBoost with Language Model Features}

Based on the promising results from the standalone \ac{CatBoost} model, we next experimented with a hybrid approach that \textbf{combines \ac{CatBoost} with outputs from \ac{BERT}-like models}. The motivation was to leverage the model's understanding of text to improve classification performance, particularly to better recognize the minority \ac{Class 3}. Initial \ac{CatBoost} experiments showed potential but struggled with \ac{Class 3} due to its rarity, so we explored whether integrating features derived from an Pre-trained Language Models could boost the model's sensitivity to these high-quality articles. \reftab{tab:catboost_hybrid_performance} summarizes the performance of the hybrid model on the validation set, comparing it to the standalone \ac{CatBoost} and \ac{DeBERTaV3} models.

In the first integration attempt, we incorporated learned \textbf{\ac{DeBERTaV3} embeddings as additional features for the \ac{CatBoost}} classifier. In this setup, each article's text was encoded into a dense vector representation by the \ac{DeBERTaV3}, and this vector was appended to the existing feature set before training \ac{CatBoost}. The intuition was that the embedding might capture complex semantic attributes of the text beyond our manually engineered features. However, \textbf{this approach did not yield any improvement} – the \ac{CatBoost} model's validation metrics remained essentially unchanged when the embedding features were added. The lack of uplift suggested that either \textit{the embedding information was redundant with our current features} or \textit{\ac{CatBoost} could not effectively leverage the high-dimensional embedding} in this configuration. 

Next, we tried a different strategy: using the \textbf{\ac{DeBERTaV3}'s predicted class label as an input feature}. In this second experiment, the \ac{DeBERTaV3} was used as a separate classifier to predict a quality class for each article (e.g. by analyzing the text and outputting a class 0–3 label). We then fed that predicted label (as a categorical feature) into \ac{CatBoost} along with all other features. The rationale was that the  \ac{DeBERTaV3}'s prediction, even if not perfect, might cue \ac{CatBoost} to certain linguistic patterns or content signals that align with quality. This method produced a \textbf{slight improvement in overall performance} – the weighted F1 score on the validation set rose to about 0.76. This was a modest gain over the baseline and indicated that the \ac{DeBERTaV3}'s judgment provided some useful signal. However, the improvement was not uniform across classes: \ac{Class 3} in particular remained difficult to detect, with its precision and recall still very low. In other words, giving \ac{CatBoost} the single class prediction from the  \ac{DeBERTaV3} wasn't enough to substantially help with the rare high-quality articles. 

Finally, our third and most successful approach was \textbf{to supply \ac{CatBoost} with the full \ac{DeBERTaV3} output logits for each class}, rather than just the single best label. In this setup, the  \ac{DeBERTaV3} produces a probability or confidence score for each class (0, 1, 2, 3) for a given article – essentially a vector of raw prediction scores across all classes, often referred to as logits. We included these four logit values as additional features alongside the existing engineered features and then trained the \ac{CatBoost} classifier on this enriched feature set. This hybrid model formulation yielded the best results: the \ac{CatBoost} +  \ac{DeBERTaV3}-logits model achieved a weighted F1 score of approximately 0.78 on the validation data, the highest of all tested configurations. The improvement suggests that providing the full distribution of the \ac{DeBERTaV3}'s predictions gave \ac{CatBoost} more nuanced information. Instead of a single guess, \ac{CatBoost} could learn from the  \ac{DeBERTaV3}'s confidence levels in each class, leveraging cases where the  \ac{DeBERTaV3} “hedged” between \ac{Class 2} and \ac{Class 3}, for example. This allowed the hybrid model to better differentiate articles, especially in borderline cases, and boosted overall classification performance. The matrix from \reffig{fig:catboost_confusion_matrix} shows that Class 1 (the majority class) had the highest number of correct predictions, with most of its errors being confusion with Class 2. In fact, the two most frequent misclassifications occurred between Class 1 and Class 2, reflecting the challenge in distinguishing adjacent quality levels. Class 3 remained the hardest category to identify correctly – the model only achieved 28 true positives for Class 3, and the majority of articles that were actually Class 3 were misclassified as Class 2. Class 0 and Class 2 also saw some confusion between each other and with Class 1, though to a lesser extent than the Class1 – Class2 overlap. This breakdown confirms that while performance for the frequent classes (0, 1, 2) was moderate to high, the \ac{Class 3} category still suffered from low precision and recall due to its scarcity and the model's difficulty in separating it from Class 2.

In summary, our experiments with integrating \ac{DeBERTaV3}-derived features demonstrated that embeddings or single-label predictions alone did not significantly enhance the \ac{CatBoost} model. In contrast, providing the \ac{DeBERTaV3} full logits as features led to a notable improvement in classification performance. This hybrid approach successfully combined the \ac{DeBERTaV3}'s language understanding with \ac{CatBoost}'s structured learning, yielding the highest overall F1 score. Therefore, the \ac{CatBoost} model enriched with \ac{DeBERTaV3} logits was selected as the final model configuration for the task, as it offered the best balance of improved accuracy (especially overall F1 $\approx0.78$) and the ability to handle all classes, including the challenging Class 3, better than previous attempts.
